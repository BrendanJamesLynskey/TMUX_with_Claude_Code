# tmux with Claude Code

An interactive Reveal.js presentation covering tmux — terminal multiplexing, session management, pane workflows, and optimal use with Claude Code.

## [Open the Presentation](https://brendanjameslynskey.github.io/TMUX_with_Claude_Code/)
